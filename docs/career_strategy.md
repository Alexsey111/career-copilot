# Career Strategy

## Purpose

Career Strategy helps a candidate understand:

- where they are really moving;
- which gaps repeat across vacancies;
- which skills most often block fit;
- which evidence is most reusable and valuable.

The goal is explainable operational guidance, not autonomous career planning.

## Data Sources

This workspace uses already available deterministic backend signals:

- vacancy intelligence;
- missing evidence;
- gap severity;
- evidence coverage trends;
- application analytics;
- application status history;
- evidence insights.

## Repeated Gap Analysis

Repeated gap analysis aggregates recurring missing skills and capability gaps across applied or reviewed vacancies.

It is intended to surface patterns such as:

- Kubernetes recurring as a missing skill;
- leadership gaps repeating across senior roles;
- system design gaps showing up in multiple fit breakdowns.

The output is explainable and tied to vacancy intelligence signals.

## Evidence Coverage Trends

Evidence coverage trends summarize how candidate evidence is being reused and where coverage is still weak.

The workspace can surface:

- most reusable evidence;
- unused evidence;
- weak evidence clusters.

This helps identify which evidence is doing useful work across multiple documents and interview prep sessions.

## Application Pattern Insights

Application pattern insights summarize how the candidate's applications are performing over time.

Typical metrics include:

- applications sent;
- interviews reached;
- offers received;
- most common rejection stage.

These signals are operational and descriptive. They are not predictive scores.

## Deterministic Recommendations

Recommendations are rule-based and explainable.

Examples:

- add stronger leadership evidence;
- create STAR examples for Kubernetes;
- strengthen quantified impact metrics;
- reuse unused evidence more effectively;
- focus on the most common rejection stage.

The recommendations are derived from recurring gaps, evidence coverage, and application outcomes.

## Explicit Non-Goals

This workspace does not do:

- predictions;
- personality profiling;
- autonomous career planning;
- psychological analysis;
- hidden AI scoring;
- hiring probability estimation.

The output is meant to stay transparent, inspectable, and operational.
