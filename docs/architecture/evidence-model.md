# Evidence Model

Evidence is the support layer for claims and recommendations.

The evidence model includes:

- evidence snippets;
- evidence usage records;
- selected evidence ids;
- evidence strength;
- fact status;
- STAR summaries;
- evidence selection reasons.

Evidence should always be linked back to a human-reviewable source where possible.
Weak, partial, or unverified evidence must stay visually distinct from confirmed evidence.
