# Provenance Model

Provenance explains why generated content contains specific claims, evidence, and matching logic.

The model is used for:

- generated resume drafts;
- generated cover letters;
- interview prep questions;
- review summaries.

Readers should prefer:

1. top-level provenance data;
2. `meta.provenance` for backward compatibility;
3. legacy meta fields only as a fallback.

Provenance should remain stable enough for support, audit, and demo UX.
