# Interview Prep Readiness

## Milestone

Interview prep is now connected to the same evidence graph used by documents.

The system can generate role-aware questions, show readiness state, link supporting evidence, and display deterministic suggested answers.

## What Is In Scope

- Interview prep session creation from vacancy and profile context.
- Question generation with gap-risk awareness.
- Readiness summary and warnings.
- Supporting evidence display.
- Suggested answer display in the Streamlit workspace.
- Deterministic answer structure:
  - Situation
  - Task
  - Action
  - Result
  - Tech stack
  - Tradeoffs
  - Talking points

## Current Quality Bar

- Suggested answers must be framed as drafts.
- Gap-risk questions should answer honestly with learning or transferable experience.
- Unsupported claims should remain visible as review risk.
- Interview prep should reuse evidence rather than invent examples.

## Non-Goals

- No claim that interview prep predicts interviewer behavior.
- No automatic employer communication.
- No final factual claims without user review.

## Demo Signal

The demo should show that interview answers are built from the same confirmed projects, evidence snippets, and competency mapping used by the resume and cover letter.
