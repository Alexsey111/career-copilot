# Portfolio Package

This package is the deterministic demo and portfolio bundle for the project.

It is designed for:

- 5 to 7 minute walkthrough video;
- architecture review;
- pilot and advisor demos;
- portfolio presentation;
- QA and product narration.

## Contents

- [Walkthrough Script](./walkthrough-script.md)
- [Architecture Diagram](./architecture-diagram.md)
- [Trust Flow Diagram](./trust-flow-diagram.md)
- [Media Checklist](./media-checklist.md)

## Recommended Flow

1. Seed the demo scene.
2. Open `System Health`.
3. Show the `Trust Panel`.
4. Walk through `Document Review Workspace`.
5. Walk through `Interview Prep Workspace`.
6. End with the readiness and trust summary.

## Core Message

The product helps a candidate prepare trusted application materials.
It does not auto-submit applications and it does not treat generated drafts as verified truth.
