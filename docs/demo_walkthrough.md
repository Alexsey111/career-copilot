# Demo Walkthrough

## Purpose

This walkthrough seeds a reproducible demo scene for operator use.

## Steps

1. Start the backend.
2. Apply migrations.
3. Run `python -m scripts.seed_demo`.
4. Start Streamlit.
5. Log in as the demo user printed by the seed script.
6. Open `Evidence Workspace`.
7. Open `Document Review Workspace`.
8. Review the seeded documents. They are already approved and active. If you create a fresh draft version during the demo, approve it in the workspace before export.
9. Open `Отклики`.
10. Open `Interview Prep Workspace`.
11. Open `Career Strategy`.

## Demo Notes

- Demo application is an internal tracker record.
- No external application is submitted.
- Seeded documents are already approved and active.
- The walkthrough stays human-in-the-loop; nothing is auto-submitted outside the app.
